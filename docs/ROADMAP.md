# NOVA Roadmap

A living document tracking NOVA's journey from a polished local-first finance app to a full cross-platform financial companion.

---

## Version 1.0 (Current)

The first production-ready release. Fully local-first, offline capable, and installable as a PWA.

- [x] Dashboard with net worth, spending, and quick actions
- [x] Wallet with grouped transaction history and search
- [x] Add Transaction (income / expense / transfer)
- [x] Goals with ETA and progress tracking
- [x] Statistics with weekly / monthly / yearly filters
- [x] Insights (AI-style behavioral summaries)
- [x] Calendar view of financial activity
- [x] Net Worth (assets & liabilities)
- [x] Subscriptions tracker
- [x] Automation rules
- [x] Receipt Scanner (simulated OCR)
- [x] AI Chat (rule-based assistant)
- [x] CSV Import
- [x] Onboarding flow (5 steps)
- [x] Settings (profile, backup, PIN, accent)
- [x] Theme system (light / dark / system)
- [x] Currency support (10 currencies with FX)
- [x] Localization (5 languages)
- [x] Diagnostics & health hub
- [x] Empty states, animations, and skeletons
- [x] Hide-balance mode
- [x] Confirm dialogs for destructive actions

---

## Version 1.1 — Infrastructure

Move NOVA from local-only to cloud-backed with real accounts.

- [ ] Authentication (email + password)
- [ ] Google Sign In
- [ ] Apple Sign In
- [ ] Supabase integration (Lovable Cloud)
- [ ] Cloud sync across devices
- [ ] Real Postgres database with RLS
- [ ] Biometric authentication (Face ID / Touch ID)
- [ ] Session management & refresh tokens
- [ ] Offline sync with conflict resolution
- [ ] Push notifications (budget alerts, bill reminders)

---

## Version 1.2 — AI

Turn NOVA into a genuinely intelligent financial companion.

- [ ] OpenAI / Lovable AI Gateway integration
- [ ] Real receipt OCR (image → structured transaction)
- [ ] Financial Assistant (conversational, context-aware)
- [ ] Natural language search ("coffee last month")
- [ ] AI Insights (personalized behavioral analysis)
- [ ] Forecasts (cash flow, savings, goal ETA)
- [ ] Smart categorization
- [ ] Anomaly detection

---

## Version 1.3 — Productivity

Polish the day-to-day experience and open NOVA to households.

- [ ] Recurring transactions (advanced rules)
- [ ] Automation (if-this-then-that flows)
- [ ] Shared wallets
- [ ] Family accounts with roles
- [ ] CSV import improvements (bank presets, auto-mapping)
- [ ] Performance optimizations (virtualized lists, code-splitting)
- [ ] Bulk edit & tags
- [ ] Advanced filters and saved views

---

## Version 2.0 — Long-Term Vision

NOVA as a full financial platform across every surface.

- [ ] Bank integrations (Plaid, TrueLayer, GoCardless)
- [ ] Open Banking (PSD2)
- [ ] Investment tracking (stocks, ETFs, funds)
- [ ] Crypto portfolio
- [ ] Desktop app (Tauri / Electron)
- [ ] Web app (installable PWA at parity)
- [ ] Home-screen widgets (iOS / Android)
- [ ] Apple Watch companion
- [ ] Android Wear companion
- [ ] Advanced analytics (cohorts, trends, projections)
- [ ] Export to accounting tools (QuickBooks, Xero)

---

_Roadmap is directional, not a commitment. Priorities shift with user feedback._
